## v0.5.0 scope (decided 2026-05-28)

**Theme: bug fix only.** GitHub milestone v0.5.0 (#9) created. Scope intentionally narrow; will be extended after triage if it makes sense.

Initial target set (highest impact first):
1. BUG-004 (critical)
2. BUG-012 (high)
3. BUG-005 (high)
4. BUG-009 + BUG-010 (high + related medium)
5. 3 Phase 4 diagnostic findings

Open question for triage: whether to fold in the cheap medium bugs (BUG-002, BUG-008) since they are low-risk one-liners, and whether BUG-013 can simply be verified-and-closed.

**Explicitly out of v0.5.0 (for now)**: all FEAT-*, DEBT-002, TECH-001/003/008/010. Adding features while 4 high/critical bugs are open is noise.

## v1.0 gates (recorded for later)

The next release after the gates below close becomes the 1.0 candidate (likely `v1.0.0-rc.1`):
1. DEBT-002: separate dev tools repository (BACKLOG trigger = "v1.0 release").
2. BUG-004 / BUG-005 / BUG-009 / BUG-012 closed.
3. 3 Phase 4 diagnostic findings closed.
4. Automated test suite (today: dogfood-only, markdown plugin).

Version-label decision (2026-05-27): sole maintainer deliberately kept v0.4.0 over jumping to 1.0; the gates above are the rationale.

## Alternative scoping considered

- **Aggressive split**: v0.5.0 = BUG fix only (short sprint), v0.6.0 = DEBT-002 + Phase 4 findings + FEAT-008. Enables frequent releases, smaller risk surface per cycle. Kept as a fallback if v0.5.0 grows too large.
