### Drift analysis

**Drift D1 — `design` secondary lists `ADR-*` in SKILL.md, profile doesn't have it**

Root cause: `ADR-*` is a **Phase 3 output artifact** (Architecture Decision Record file written to `.s2s/decisions/`), not an in-session Phase 2 artifact embedded in `session.yaml.artifacts`. The profile only lists in-session artifact types. SKILL.md table conflates two categories.

**Resolution (7.1b)**: keep `ADR-*` in SKILL.md table but add inline clarification: `"ADR-* is a Phase 3 output artifact (written to .s2s/decisions/), not an in-session artifact"`. Alternative: remove ADR-* from this table (cleaner, but loses information). Recommend the clarification approach for human readability.

**Drift D2 — `brainstorm` secondary has `CONF` in profile, SKILL.md doesn't list it**

Root cause: `CONF` (conflicts) is a generic in-session artifact for ALL workflows when conflicts arise. The profile correctly includes it for brainstorm. SKILL.md omits it for brainstorm — likely an authoring oversight when the table was created.

**Resolution (7.1b)**: add `CONF` to SKILL.md `brainstorm` secondary list to match profile.
